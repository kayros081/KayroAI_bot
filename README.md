

Telegram-бот для демонстрации работы с языковыми моделями (Qwen / Llama) и вспомогательными утилитами. Проект создан в учебных целях.

## Возможности

*   💬 Диалог с AI: Отправь боту сообщение — получи ответ от языковой модели.
*   ⚙️ Поддержка разных моделей: Интеграция с Qwen, Llama.
*   🗄️ Контекст диалога: обе модели помнят последние 40 сообщений в истории диалога после превышение лимита модель обрезает историю до 24 сообщений
*   📝 Дополнительные утилиты: можно сохранять конспекты форматов: текстовые, голосовые и фото, оставлять теги для быстрого поиска и удалять конспекты 

## Технологии

*   Python 3.14
*   aiogram 3.x
*   LLM API: HuggingFace API
*   База данных: aiosqlate
*   Другие библиотеки:  python-dotenv, huggingface_hub, SQLAlchemy

## Запуск

1.  Клонируй репозиторий:
   
    git clone https://github.com/kayros081/KayroAI_bot.git
    cd KayroAI_bot
    
2.  Установи зависимости:
   
    pip install -r requirements.txt
    
3.  Создай файл .env и добавь в него токен твоего Telegram-бота и API-ключ для LLM:
   
    BOT_TOKEN=токен_бота_от_BotFather
    HF_TOKEN=твой_ключ_с_HuggingFace
    
4.  Запусти бота:
   
    python run.py
    
## О проекте
